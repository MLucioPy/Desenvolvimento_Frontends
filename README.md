# Página em HTML5 do Projeto IoT Web

Esta é a versão final do site, e adicionamos comentários no HTML, CSS e JavaScript.

## Como abrir
1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. Navegue pelas páginas pelo menu.
4. Para a simulação, abra **Arquitetura** e clique em **Simular alerta**.

## Estrutura
- `index.html` — página inicial.
- `projeto.html` — problema, objetivos, requisitos e escopo.
- `arquitetura.html` — fluxo do sistema e simulação.
- `componentes.html` — componentes, tabela e imagens.
- `cronograma.html` — etapas do desenvolvimento.
- `resultados.html` — critérios de aceitação e conclusão.
- `css/style.css` — aparência, layout e responsividade.
- `js/script.js` — interações do menu e simulação.

## Observação importante
As imagens são carregadas por URLs externas. Portanto, quando o site estiver hospedado no GitHub Pages, é necessário que o dispositivo tenha acesso à internet para visualizar essas imagens.

O botão de alerta é uma **simulação no navegador**. Ele não se conecta de verdade ao ESP32, MQTT ou a sensores.
